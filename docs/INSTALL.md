# Scan2Read 설치 가이드

## 1. 다운로드

[Releases 페이지](../../releases/latest)에서 `Scan2Read-Setup.exe`를 받습니다. 약 120MB입니다.

## 2. "Windows에서 PC를 보호했습니다" 경고

실행하면 아래와 같은 경고가 뜰 수 있습니다.

> Windows에서 PC를 보호했습니다
> Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 차단했습니다.

Scan2Read가 아직 정식 코드 서명 인증서로 서명되지 않은 초기 배포판이라 나오는 정상적인 경고입니다. **추가 정보**를 클릭한 다음 **실행**을 누르면 설치를 계속할 수 있습니다.

일부 백신 프로그램도 같은 이유(서명 없는 신생 실행 파일)로 오탐지할 수 있습니다. 걱정되면 [소스 코드](../README.md#개발자용)를 직접 받아 빌드해서 쓸 수 있습니다.

## 3. 설치

1. `Scan2Read-Setup.exe`를 실행합니다. **관리자 권한이 필요하지 않습니다** — 사용자 계정에만 설치됩니다.
2. 설치 위치를 확인합니다(기본값: `%LOCALAPPDATA%\Programs\Scan2Read`). 바꾸고 싶으면 "설치 위치 선택"을 누르되, **빈 폴더**를 골라야 합니다.
3. "설치"를 누릅니다. 인터넷 연결이 필요합니다 — 기본 프로그램을 푸는 것 외에 PaddleOCR·Kiwi(띄어쓰기 보정)·한국어 OCR 모델(약 250MB)을 추가로 내려받아 설치합니다.
4. 설치가 끝나면 "Scan2Read 실행" 버튼으로 바로 시작하거나, 시작 메뉴에서 Scan2Read를 찾아 실행합니다.

설치 후 디스크 사용량은 약 1.2GB입니다.

## 4. GPU 가속 (선택, NVIDIA GPU만 해당)

RTX/GTX 등 **NVIDIA GPU가 있는 PC**에서는 프로그램 안 "변환 설정" 탭에 "GPU 가속 다운로드" 버튼이 나타납니다. 누르면 CUDA 런타임(약 2GB)을 추가로 받습니다. 인텔/AMD 내장그래픽은 지원하지 않으며, 이 경우 버튼 자체가 나타나지 않고 자동으로 CPU 모드로 동작합니다(설치 용량에도 영향 없음).

## 5. 문제 해결

- **설치가 중간에 실패했어요**: 대부분 설치 중 다운로드가 끊겨서입니다. 인터넷 연결을 확인하고 설치 프로그램을 다시 실행하세요(같은 빈 폴더를 다시 선택하면 됩니다).
- **"설치 폴더가 비어 있지 않습니다" 오류**: 이전에 설치를 시도했던 폴더입니다. 폴더를 비우거나 다른 빈 폴더를 선택하세요.
- **실행은 되는데 GPU 버튼이 안 보여요**: NVIDIA GPU가 없거나 드라이버가 인식되지 않는 경우입니다. 내장그래픽(인텔/AMD)에서는 원래 나타나지 않습니다.
- **회사/학교 PC라 관리자 권한이 없어요**: 관리자 권한 없이도 설치되도록 만들어졌습니다(사용자 폴더에만 설치). 그래도 막힌다면 보안 정책(SmartScreen, 백신, 그룹 정책)이 실행 자체를 막고 있는 경우이니 IT 담당자에게 문의하세요.

## 6. 제거

- **설정 → 앱**(또는 제어판 → 프로그램 및 기능)에서 Scan2Read를 찾아 제거하거나,
- 설치 폴더 안의 `uninstall.ps1`을 실행합니다.

제거해도 **변환된 EPUB과 OCR 캐시는 삭제되지 않습니다.**
