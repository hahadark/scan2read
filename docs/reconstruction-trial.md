# 줄바꿈과 문단 재구성 시험

변환기의 `--reconstruct`와 GUI의 "문맥·줄바꿈·문단 보정"은 기존 원본 JSON의
좌표·읽기 순서를 이용한다. OCR 재실행 없이 반복 머리글과 페이지 번호를 제외한 후
다음 기준을 적용한다.

- 같은 단의 일반 줄은 연결한다.
- 들여쓰기, 큰 수직 간격, 번호 목록, 짧은 제목은 문단 경계로 유지한다.
- 단/페이지 경계는 앞줄이 하단 끝까지 차고 다음 줄이 상단의 들여쓰기 없는
  본문이며 종결 문장부호가 없을 때만 연결한다.
- 빈 페이지, 페이지 번호 건너뜀, 제목, 완결 문장에서는 연결하지 않는다.
- PDF 텍스트 레이어가 단어 조각을 반환하면 가까운 조각을 먼저 시각적 한 줄로 묶는다.
- 위치만으로 문단이 갈린 경우 Kiwi 형태소 분석에서 조사·연결어미·관형형처럼
  문장이 끝날 수 없는 경계만 추가로 연결한다.

각 문단은 `(페이지 번호, 원본 블록 ID)`를 보관한다. 재구성 뒤 Kiwi 공백 보정을
적용하되 공백 외 문자는 변경하지 않는다. 기존 Raw OCR 해시와 본문 글자 순서의
동일성을 실행 시 확인한다. 전문용어와 OCR 오인식은 별도로 남아 있다.

실행: `.\.tools\paddle-env\Scripts\python scripts/trial_reconstruction.py`

5페이지 결과: 기존 16문단을 32문단으로 재구성, 페이지 경계 4곳 연결,
EPUBCheck 통과. 결과는 `output/ivp-sample/ivp-pages-30-34-paragraphs.epub`이며
`paragraphs-trace.json`에 추적 정보를 저장한다.
2026-09-08 실제 `고대 근동 역사.pdf`의 캐시 482쪽을 다시 구성한 결과,
113,853개 원본 블록이 위치 판정만으로 5,266문단, 문맥 판정 후 4,742문단이 됐다.
모든 결과 문단에서 공백을 제외한 글자와 연결된 원본 블록의 글자가 일치했으며
Raw OCR은 변경하지 않았다.
문단 판정은 위치 기반 추정이므로 모든 책의 문단을 정확히 복원한다고 보장하지 않는다.
