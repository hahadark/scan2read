# Scan2Read 사용 안내

설치는 [설치 가이드](INSTALL.md)를 참고하세요. 이 문서는 설치 후 사용법입니다.

## 화면 구성

3개 탭으로 나뉩니다.

- **변환**: 파일 목록, 시작/중단, 로그
- **변환 설정**: 출력 폴더, 파일명 규칙, 단 수, 보정 옵션, GPU, 동시 처리 개수
- **AI 설정**: AI 제공자·모델·키·기능·비용

## 기본 사용 순서

1. **변환** 탭에서 PDF 추가·폴더 추가 또는 드래그 앤 드롭으로 파일을 목록에 추가합니다. 폴더를 끌어다 놓으면 그 폴더 바로 아래 PDF만 추가합니다(하위 폴더 제외).
2. **변환 설정** 탭에서 출력 폴더(비워두면 원본과 같은 폴더)와 파일명 규칙(`{name}`, `{folder}`, `{index:03d}`)을 정합니다.
3. 책 편집에 맞게 단 수(1/2단)를 고르고, 필요하면 각주 제거·페이지 범위를 설정합니다.
4. **변환** 탭에서 변환 시작을 누릅니다.
5. 완료되면 "결과 파일 위치 열기"로 EPUB을 찾습니다.

여러 파일을 한 번에 처리할 수 있고, 하나가 실패해도 나머지는 계속됩니다. 목록에 파일별 상태(대기·진행률·완료·실패·중단)가 표시됩니다. "중단"을 누르면 진행 중인 작업을 멈추고 나머지 대기열은 취소됩니다.

## 보정 옵션 (변환 설정 탭)

로컬에서 동작하며 인터넷이 필요 없습니다.

- **문맥·줄바꿈·문단 보정**: PDF 텍스트 레이어가 단어 단위로 쪼개진 경우, 줄 길이·들여쓰기·간격과 Kiwi 형태소 분석으로 끊어진 문장을 연결합니다.
- **각주 제거** (실험적, 기본 꺼짐): 페이지 하단의 작은 글씨·번호로 시작하는 문단을 각주로 보고 제거합니다. 드물게 오탐지할 수 있습니다.
- **괄호 안 내용 제거** (기본 꺼짐): "지라(계2:5)"처럼 괄호로 묶인 인용을 낭독용 텍스트에서만 뺍니다(원본은 보존). 괄호 개수가 안 맞으면 그 문단은 건드리지 않습니다.
- **텍스트 레이어 무시하고 항상 OCR**: PDF에 이미 텍스트가 있어도 믿지 않고 직접 OCR합니다. 원본 PDF의 텍스트 품질이 낮을 때 켭니다.

## GPU 가속

**NVIDIA GPU(CUDA)만 지원**합니다(인텔/AMD 내장그래픽 불가). GPU가 감지되면 "GPU 가속 다운로드" 버튼이 나타나고, 설치 후 체크박스로 켜고 끌 수 있습니다. CPU 대비 수십 배 빠르며, 실시간 GPU 사용률·VRAM 사용량이 표시됩니다.

**동시 처리 개수**(1~4, 기본 2)는 OCR 프로세스를 몇 개 동시에 돌릴지 정합니다. 값이 클수록 GPU 메모리를 더 씁니다(프로세스마다 모델을 따로 올림). 2 이상이면 큰 책은 페이지 구간을 나눠 병렬 처리 후 자동으로 EPUB을 조립합니다. GPU 메모리가 부족하면 값을 낮추세요.

## AI 보정 (AI 설정 탭, 선택 사항)

`AI 기능 전체 사용`을 켜면 로컬 판정으로는 애매한 부분을 AI로 보강합니다. 켜지 않아도 변환은 정상 동작합니다.

- 제공자(OpenAI/Claude/Gemini)와 모델을 하나씩 고르고 API 키를 입력합니다(키는 제공자별로 암호화 저장).
- 기본 모델은 저렴한 모델입니다. 목록에 없는 모델 ID도 직접 입력할 수 있으나, 요금을 몰라 가장 비싼 요금으로 추정합니다.
- PDF나 페이지 이미지는 보내지 않고 OCR 텍스트만 전송합니다. 키가 없거나 요청이 실패하면 로컬 판정으로 계속 진행합니다.
- 변환 전 예상 비용, 변환 중 누적 비용·진행률이 표시됩니다. 책당 비용 한도를 정하면 한도를 넘기 전에 자동으로 로컬 처리로 전환됩니다.
- 제공 기능: 문단 경계 판정, OCR 의심 단어 보정, 띄어쓰기, 이상 문자, 본문 구조, EPUB 목차, **괄호·음역 중복 표현 삭제**(예: "정의(체다카)"에서 뒷부분 삭제 — 로컬 옵션과 달리 괄호가 OCR로 깨진 경우도 처리).

## 설정과 데이터 위치

- 설정 파일: `%LOCALAPPDATA%\Scan2Read\settings.json` (출력 폴더, 이름 규칙, 단 수, 보정 옵션 등 자동 저장·복원)
- OCR 캐시: `%LOCALAPPDATA%\Scan2Read\work` (중단 후 재개 시 완료된 페이지 재사용, 프로그램 제거해도 보존)
